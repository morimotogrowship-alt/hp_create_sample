# water-garden（MINAMO — 水面の庭）

Three.js で作ったインタラクティブな3D水庭。水面をなぞると波紋と流れが生まれ、浮かぶ葉が運ばれ、底の玉石が屈折して揺らいで見える。

- `index.html` 単体で動作（Three.js r169 と Google Fonts を CDN から読み込むため、ネット接続が必要）
- 操作：水に触れる／石を動かす／水門を開く・閉じる／↺ 葉を戻す

## 仕組み

- 波紋：GPU上の高さ場シミュレーション（256×256）
- 流れ：CPU上の簡易 Stable Fluids（80×56）で葉を移流・回転
- 屈折：水面を除いたシーンを一度テクスチャに描き、水面法線でUVをずらす
- コースティクス：高さ場のラプラシアンから池底の明るさを変調

## 動作要件

WebGL2 と半精度浮動小数テクスチャへの描画に対応したブラウザ。低スペック端末では重い場合がある。
